# 阅见 · 图书借还管理

基于 Java 21、Spring Boot 4.1.1、原生 HTML/CSS/JavaScript 和 JDBC 的本地图书借还管理系统。

## 使用

安装 Java 21 和 Maven 3.9 后，下载或克隆本仓库，双击项目中的 `启动本地版.cmd`。首次启动会自动编译并下载依赖，程序就绪后会自动打开浏览器：

http://127.0.0.1:8088

也可以在 PowerShell 中执行：

```powershell
# 先在终端进入本仓库目录
mvn spring-boot:run
```

双击项目中的 `停止本地版.cmd` 可停止双击启动的后台进程。若用 Maven 在终端启动，按 Ctrl+C 停止。程序仅绑定 `127.0.0.1`，当前版本用于本机访问。

## 数据来源

- 默认打开 **示例预览**。独立 H2 内存数据库使用原始四份 CSV 的数据，读者电话留空，重启后恢复，和 MySQL 相互独立。
- 点击左下角数据来源或页面顶部的 **连接我的 MySQL**，填写本机 MySQL 账号和密码。
- 连接目标固定为 `127.0.0.1:3306/librarydb`。成功后即使用现有表和数据，不自动建表、导入 CSV 或覆盖数据。页面上的增删改会实际保存到 MySQL。
- 账号密码只保留在当前进程内存，不写入项目文件，不保存在浏览器存储中；停止程序后需要重新连接。建议使用只获准访问 librarydb 的专用账号。
- MySQL 四张表结构与项目实训表一致；借阅表需要自增主键 `id`。尚未准备 MySQL 数据库时，可以先使用完整的示例预览功能。

## 功能

- 工作台：馆藏、可借库存、读者、借出、逾期、热门图书和院系分布。
- 图书：新增、编辑、删除、搜索、库存筛选和分页。
- 读者：新增、编辑、删除、类别筛选和借阅额度。
- 借还：登记借阅、归还、借阅历史、状态筛选和应还日期。
- 借还事务及行锁：库存不足、借阅上限、重复借阅、重复归还均有检查。
- 兼容现有还书库存触发器：触发器已正确更新库存时不会再次累加；库存变化异常时回滚。
- 有历史记录的图书、读者禁止删除，保留借阅历史。

原始 CSV 借阅日期为 2022 年，至今未归还的记录显示逾期属于预期行为。应还日期按读者类别表当前 `max_days` 计算。

## 验证与打包

```powershell
mvn test
mvn package
java -jar target/library-0.0.1-SNAPSHOT.jar
```

自动化测试使用独立的 H2 数据库，覆盖事务、并发抢最后一本书、库存触发器和重复归还等情况。它们不连接或修改用户 MySQL。

## 仓库与本地文件

仓库包含应用源码、示例数据、测试和启动脚本。`target/`、`.local/`、日志和本地环境配置已通过 `.gitignore` 排除。原始 Word 文档及 CSV 保留在本机项目目录之外，不随本仓库上传。

本版本用于本地运行，未配置公网身份认证或部署。GitHub 仓库用于保存代码；浏览器访问应用仍需在本机启动程序。
